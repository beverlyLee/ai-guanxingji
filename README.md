# ai-guanxingji · AI 观星记

「AI 观星记」是一档用**一个数学知识点 + 一个公开数据集 + 一个真实故事**串起来的数据科普专栏。每篇都用可复现的 Python 脚本从原始数据长出全部数字与配图，拒绝编造。

本仓库按篇归档：每篇一个 `Hn/` 子目录，内含「主文章 `.md` + `code/`（复现脚本）+ `data/`（原始数据）+ `figures/`（配图）」。所有文章已在文末注明本篇 GitHub 路径。

## 复现方式

进入任意 `Hn/code/` 或 `Mn/code/` 目录，用 Python 运行对应脚本即可（依赖 `numpy` / `pandas` / `scipy` / `matplotlib`，M 系列另用 `scikit-learn`）。每篇主文章末尾的验证小节给出了本篇复现脚本名。

> 说明：本仓库只收录「代码 + 数据 + 配图 + 主文章」，运营 / 多平台发布物料不在其中。
